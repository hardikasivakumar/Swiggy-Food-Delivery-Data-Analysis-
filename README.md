# Swiggy Food Delivery Database

## Overview

The **Swiggy Food Delivery Database** is a relational database project developed using MySQL to simulate the backend operations of an online food delivery platform. The project demonstrates effective database design, normalization, and SQL querying for managing customers, restaurants, menu items, orders, payments, delivery partners, and customer reviews.

It provides a practical implementation of SQL concepts commonly used in real-world database applications and business analytics.

---

## Objectives

* Design a normalized relational database for a food delivery system.
* Manage customer, restaurant, menu, order, and payment information efficiently.
* Demonstrate SQL concepts through real-world business scenarios.
* Perform analytical queries to generate meaningful business insights.

---

## Database Modules

The database consists of the following core modules:

* Customer Management
* Restaurant Management
* Menu Management
* Order Management
* Payment Management
* Delivery Partner Management
* Customer Reviews

Each module is connected through appropriate primary and foreign key relationships to ensure data consistency and integrity.

---

## Key Features

* Well-structured relational database design
* Normalized tables to minimize redundancy
* Referential integrity using foreign keys
* Business-oriented SQL queries
* Support for customer orders and payment tracking
* Restaurant and menu management
* Delivery partner information management
* Customer review management

This project demonstrates the use of:

* GROUP BY and HAVING

## Sample Business Queries

The database supports queries such as:

* Display customer information
* Calculate total revenue
* Identify top customers by spending
* Find the most popular restaurants
* Display successful and failed payments
* Analyze restaurant ratings
* Retrieve top-selling menu items
* Generate order and sales reports
* Track delivery performance
